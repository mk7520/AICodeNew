بوت تلغرام متخصص في كتابة الأكواد البرمجية باستخدام الذكاء الاصطناعي.

## ✨ المميزات

- 📝 **كتابة كود** - توليد أكواد برمجية بجودة عالية
- 🔧 **تحسين الكود** - إعادة هيكلة وتحسين أداء الكود
- 📖 **شرح الكود** - تحليل وتفصيل الكود المعقد
- ✅ **اختبارات وحدة** - إنشاء اختبارات تلقائية
- ☁️ **حفظ سحابي** - حفظ ومشاركة الأكواد
- 📊 **تحليل الجودة** - تقييم جودة الكود
- 🏆 **تحديات يومية** - تحديات برمجية ونقاط
- 📦 **تصدير المشاريع** - تصدير الكود كملف ZIP

## 🛠️ التقنيات المستخدمة

- Python 3.9+
- python-telegram-bot
- OpenAI API (GPT-3.5/4)
- Redis (تخزين مؤقت)
- SQLAlchemy (قاعدة بيانات)
- Loguru (سجلات)
